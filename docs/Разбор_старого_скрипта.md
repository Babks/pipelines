## Как читать старый код

Номера строк относятся к неизменённой копии `docs/reference/legacy/vtd_corrosion_mvp.py`.

| Строка / функция | Что делает | Откуда берёт значения |
|---|---|---|
| 41, `_as_float` | Преобразует вход в число, проверяет пропуски, bool, бесконечность и NaN | Значение поля Excel |
| 68, `SimpleXlsxReader` | Открывает XLSX как ZIP, читает XML листов и строки общего словаря | Сам файл XLSX; Excel для этого не запускается |
| 111, `read_table` | Превращает строку в словарь, добавляет `_excel_row` | Заголовки первой строки становятся ключами |
| 407, `find_pipe_row` | Находит соответствующую трубу | `n_tube`, `id_mu`, `pass_vtd`; при нескольких кандидатах `rasst_do_nach_tube` |
| 431, `_axial_interval_mm` | Строит начало и конец дефекта вдоль оси | Координата ×1000 и длина дефекта; это предположение о метрах координаты |
| 463, `_circumferential_gap_mm` | Вычисляет расстояние между границами по окружности | Центры в 12-часовом формате, ширины, диаметр |
| 491, `pair_interaction` | Сравнивает зазоры с порогами, возвращает isolated/interacting/undetermined | Геометрия двух дефектов |
| 548, `build_inputs` | Формирует аргументы формул | Параметры трубы преимущественно из weld, длина и глубина из anom |
| 202, `_pressure_for_geometry` | Вычисляет Q и разрушающее давление | D, t, прочность материала, длина, глубина |
| 222, `_sto_safety_factor` | Вычисляет R1, gamma и K_STO | Материал, рабочее давление и коэффициенты |
| 365, `calculate_single_defect` | Собирает расчёт одиночного дефекта | Две предыдущие функции; допустимое давление = разрушающее / K_STO |
| 577, `_build_interaction_components` | Строит граф связей и объединяет связанные дефекты | Результаты попарного взаимодействия |
| 647, `_projection_items` | Объединяет перекрывающиеся осевые интервалы | Координаты, длины, глубины и EXT/INT |
| 695, `calculate_group_component` | Перебирает непрерывные комбинации подготовленной последовательности, выбирает минимальное давление | Схематизированные элементы группы |
| 240, `_tz_safety_factor` | Отдельно вычисляет K_TZ для категорий | n, k1, kh, m, константа Up=2.33 |
| 316 / 340, `calculate_danger_*` | Назначает A/B/C по текущему состоянию и прогнозу | Давление, глубина, K_TZ, прогноз через 3 года |
| 295, `_solve_tno_years` | Ищет время достижения порога бисекцией | Функция прогнозного давления; предел поиска 200 лет задан в программе |
| 836, `analyze_workbook` | Управляет всей последовательностью обработки | Листы anom/weld, затем перечисленные функции |
| 981, `write_csv` | Сохраняет итоговую таблицу | Результаты расчёта, разделитель `;`, десятичная запятая |
| 1120, `main` | Читает аргументы командной строки и выбирает режим | Путь XLSX, ID, поле давления и флаги |

`dict[str, Any]` — словарь с текстовыми ключами и значениями разных типов. Это удобно для прототипа, но почти не защищает от неверных имён полей. `dataclass` задаёт именованную структуру результата. `None` означает отсутствие значения, а не ноль. `raise DataError(...)` прерывает обработку с сообщением. `if __name__ == '__main__'` запускает CLI только при прямом запуске файла, а не при импорте.

## Прослеживаемый пример: дефект 91199328

Источник — небольшая выгрузка `0936a617…xlsx`, `anom`, строка 31. Связанная труба — 1364. В старом коде значения трубы сначала берутся из подходящей записи weld; если поле там пустое, используется anom. Приоритет задан функцией `_value_from_pipe_or_defect`, а не формулой СТО.

| Переменная | Поле anom и ячейка контрольной строки | Значение |
|---|---|---:|
| D | `diameter`, BX31 | 530 мм |
| t | `tolschina_sten_tube`, G31 | 7 мм |
| σвр | `predel_prochnosti`, J31 | 510 МПа |
| l | `osob_dlina`, AL31 | 25 мм |
| d | `osob_glubina`, AN31 | 1 мм |
| c | `osob_shirina`, AM31 | 73 мм |
| p, выбранное старым кодом | `pd`, AU31 | 5,39 МПа |
| n | `koeff_nadegn_n`, BF31 | 1,1 |
| k1 | `koeff_nadegn_k1`, BC31 | 1,34 |
| kh | `koeff_nadegn_kh`, BD31 | 1 |
| m | `koeff_uslovii_m`, BE31 | 0,9 |

Последовательность: Excel → словарь строки → соответствующая труба → проверка взаимодействия → аргументы формул → Q → разрушающее давление → R1/gamma/K_STO → допустимое давление → отдельное категорирование K_TZ → прогноз.

В диагностическом запуске старый код вернул Q=1,025780, pкр=13,595063 МПа, K_STO=1,448486, pдоп=9,385703 МПа. Поле `pf=13,596` используется только для сравнения: расхождение −0,000937 МПа. Поле `danger=(c)` — исходная категория, а не доказательство собственного расчёта.

Прогнозный срок старого кода для этой записи — 22,758539 года, тогда как `srok_obsled_tube` содержит 21,67. Это расхождение остаётся открытым. Совпадение одного давления не подтверждает весь алгоритм и смысл всех полей.
