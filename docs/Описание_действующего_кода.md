# Как устроен действующий код

Это описание относится к Workbench, а не к сохранённому демонстрационному App.tsx.

## Путь данных

`desktop.py` создаёт свободный локальный порт, запускает FastAPI в потоке и открывает нативное окно. Случайный токен передаётся через fragment URL; api.ts сохраняет его в сеансе и добавляет заголовок X-VTD-Session. Закрытие окна останавливает сервер.

`ImportWorkbook.tsx` передаёт выбранный файл multipart-запросом. `main.py` проверяет размер/расширение и вызывает `analysis.import_project`. `workbooks.py` читает книгу без исполнения формул: каждая запись содержит значения, номер строки и словарь источников с адресами ячеек. Пустые строки пропускаются, отсутствующие числовые поля не становятся нулями.

`analysis.py` связывает anom с weld по id_mu/pass_vtd/n_tube. При нескольких совпадениях дополнительно проверяет начало трубы. Параметры трубы берутся из weld, при отсутствии — из anom; конфликт значений считается ошибкой. Входы и выбранные ячейки сохраняются в inputs/inputSources. raw содержит исходные поля, result — вычисленный результат, это разные объекты.

`legacy_core.py` содержит перенесённые функции старого скрипта: одиночный расчёт, коэффициенты, проверку взаимодействия и категорирование. Исходная копия хранится в docs/reference/legacy. `spatial_groups.py` выполняет пространственную обработку; `group_forecast.py` повторяет её после роста размеров и расширяет группу новыми взаимодействующими соседями. Геометрия группы в реестре: полный осевой размах, максимальная глубина участников; окружная ширина не подменяется шириной первого дефекта. Эффективная геометрия опасной комбинации находится в steps.critical.

`dent_rm3.py` реализует только доступные положения малых вмятин. Подтверждение отсутствия вторичных повреждений вводится с основанием пользователем и сохраняется в dentAssessments; это не автоматическое заключение по пустой ячейке. A/B в preliminaryCategory не копируются в окончательную category.

`storage.py` сохраняет JSON проекта в SQLite транзакцией. Проект содержит исходные таблицы, поэтому пересчёт не требует повторной загрузки. API скрывает полные tables в ответе интерфейсу, но оставляет происхождение каждой записи. Экспорт пишет числа числовыми ячейками, а строки — текстом.

`Workbench.tsx` хранит выбранный проект, фильтры, страницу и ID выделенной записи в React state. useMemo строит отфильтрованный массив; Table сортирует и разбивает его на страницы. Закрытие Drawer меняет только open, поэтому фильтры сохраняются. CalculationCard показывает исходные ячейки, входы, промежуточные величины и сообщения результата.


## Прослеживаемость величин

Путь величины: книга → sheet/cell → inputs → расчётная функция → result.steps → компонент. K_STO используется для допустимого давления, K_TZ — для категорирования.
