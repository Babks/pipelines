# Настольное приложение

Команды установки, запуска и сборки: [README](../README.md).

`desktop.py` запускает локальный FastAPI на свободном порту и открывает React-интерфейс в pywebview. При закрытии окна сервер останавливается. Проекты сохраняются в SQLite.

`start-windows.ps1 -Setup` создаёт окружение, устанавливает зависимости и собирает интерфейс. Повторный запуск выполняется без `-Setup`.

`bash start-linux.sh --setup` выполняет установку для Linux; повторный запуск — без `--setup`. Скрипт выбирает Qt и использует `.venv/bin/python`.

`build_desktop.py` упаковывает приложение средствами PyInstaller для текущей ОС.
