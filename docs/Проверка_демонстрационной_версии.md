# Устройство проверок интерфейса

Vitest проверяет фильтрацию и компоненты в jsdom. Файлы находятся в frontend/src/__tests__.

Playwright запускает сценарии в Chromium. frontend/e2e-server.mjs создаёт временную БД и запускает API. Сценарии frontend/e2e проверяют импорт XLSX, открытие карточки, раскрытие группы, экспорт, сохранение проекта и ошибку повреждённой книги.

Команды из frontend: `pnpm test` и `pnpm test:e2e`. Для установки браузера: `pnpm exec playwright install chromium`.
